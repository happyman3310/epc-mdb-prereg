# epc-mdb-prereg

Предрегистрация протоколов пяти научных работ (ГУУ, 2026/27). Здесь публикуются только SHA-256 хэши файлов протоколов
(гипотезы, условия опровержения, решающие правила, правила выборки), зафиксированных **до сбора данных**.
Сами протоколы будут опубликованы позже вместе с основным репозиторием; любой может проверить, что они не менялись:
`sha256sum <файл>` должен совпасть со значением в `HASHES.md` на дату коммита.
